# Caregiver Compass KC — Project Overview

An interactive cancer caregiver support navigator developed as a UMKC student project.

## Live Demo

https://sathwikmareddy.github.io/caregiver-compass-kc/

## Project Objective

Help family caregivers of people with cancer identify immediate needs, understand unfamiliar medical terminology, and find actionable support resources in the Kansas City region.

## Implemented Features

- Personalized caregiver needs assessment and resource recommendations
- Cancer terminology glossary with plain-language explanations
- Financial assistance checker with service-area and eligibility guidance
- Personal action dashboard and progress tracking
- Request Help message generator for friends and family
- Cancer support resource library
- Donations and volunteer opportunities
- Responsive interface for desktop and mobile

## Technology Stack

HTML, CSS, JavaScript, Node.js for automated testing, and GitHub Pages for deployment.

The current recommendation system uses explainable rule-based matching. It does not depend on a trained AI model.

## Running Locally

1. Download or clone the repository.
2. Open index.html with a browser or VS Code Live Server.
3. To run automated tests, use: node --test tests/*.test.js

## Privacy and Safety

This is an educational prototype, not a medical diagnosis or treatment system. Resource recommendations do not guarantee eligibility, funding, or availability. Users should confirm program details with providers.

Do not enter private patient records or sensitive identifying information into the public demo.
